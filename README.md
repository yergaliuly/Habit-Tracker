# Streaks

Habit tracker with streaks and an activity calendar.

**Stack:** React + Vite, Node.js + Express, PostgreSQL + Prisma, JWT auth

## Features

- [ ] Registration and login
- [ ] Create / edit / delete habits
- [ ] Daily check-ins
- [ ] Streak statistics
- [ ] Activity calendar

## Getting started

```bash
# server
cd server
npm install
cp .env.example .env
npx prisma migrate dev
npm run dev

# client
cd client
npm install
cp .env.example .env
npm run dev
```
